# 腳本執行與本機／遠端往返

## 分辨三種能力

| 能力 | 所需證據 |
|---|---|
| 檔案往返 | CAD 讀到本輪腳本／輸入，產生本輪可識別輸出，本機讀到完整內容 |
| 觸發執行 | 使用者手動 Command，或已驗證可進入正確 CAD session 的自動入口；分開記錄 |
| 設計結果 | 指定操作後置條件、恢復、連通／DRC等對應證據 |

檔案可見、load 成功、往返 marker 或 shell 可連線，均不能推定 GUI CAD 已自動執行，更不能推定 routing 成功。

若使用者已測通手動 Command＋本機直接讀回，就沿用這條路完成已授權工作。只有明確要求自動觸發時才研究該入口；不要讓未完成的自動化研究阻塞已有的手動流程。無已驗證入口時，交付實際可執行的手動命令，清楚標示誰觸發。

## 選擇已有可用的傳輸路徑

先記錄腳本由誰寫、在哪個主機／session 執行、報告在哪裡讀，以及雙方對同一檔案的路徑映射。RDP 磁碟重導向已啟用時，遠端可能使用 `//tsclient/<drive>/...`；必須由該 CAD session 實際讀寫驗證，不能假設本機絕對路徑在遠端也有效。

共享目錄、NAS、RDP 或其他通道依實測選用；不為了固定流程要求重複搬檔，也不從一個主機可連線推定它與 GUI session 共用檔案系統。新增分享範圍或遠端控制沿用當前授權，不自動開放整顆磁碟。公開 skill 不包含真實主機、帳戶、IP、映射路徑與 bootstrap 私有程式。

先做小型唯讀往返測試，再執行設計操作。大幾何輸出若使傳輸卡住，依實測改成近 CAD 端保存完整資料、將精簡摘要與來源 hash／取得方式回寫。摘要不是完整幾何的替代證據；需要全資料的驗證仍需取得對應檔案，不將固定大小門檻視為通用規則。

## 每次執行的報告契約

按現有格式補足以下欄位；不是要求重寫已有效的輸出格式。

| 欄位 | 內容 |
|---|---|
| 識別 | 唯一 run ID／nonce、腳本版本／hash、mapping／placement版本 |
| 環境 | 工具版本、設計身份、單位／精度、執行session及開始／結束時間；未知值明列 |
| 範圍 | READ_ONLY、TEMPORARY_MUTATION 或 APPLY，預期變更及檢查覆蓋 |
| 結果 | 實際執行步驟、數量、warning、缺欄、errors與完整結束marker |
| 狀態 | board_modified、rollback驗證、儲存狀態、未完成後置條件 |
| 產物 | 本輪輸出路徑／hash；大型原始資料及摘要的對應關係 |

每輪使用新識別或檔名，完成寫入／關閉輸出後才發布完成狀態；接收端對上本次 run ID 和版本。既有檔案存在、mtime較新或前一次成功標記均不足以證明本次完成。

交付載入命令與入口呼叫時，核對當前是在 Allegro Command 或 SKILL 提示符，避免重複／缺少前綴。路徑引號與跳脫須符合該語言；SKILL路徑可用正斜線降低反斜線歧義。純腳本檔不可夾Markdown fence。API簽名、字串／symbol、集合操作及opaque物件處理以安裝版本的小範圍測試為準，不從另一Lisp方言直接推定。

## 逾時、重連與重跑

先區分未觸發、執行中、輸出未完成及設計已部分修改。逾時不等於取消或rollback；在結果不明時先讀回現況，不自動重放apply。重新連線後重新確認同一設計、路徑映射與新鮮run ID，不沿用失效DBID。

若有獲授權的自動入口，限制同一設計的相依寫入依序執行，提供重入防護及可觀察狀態。先證明單次唯讀觸發／讀回，再評估寫入；執行權限取決於操作內容與授權，檔名含不含apply不能代替判斷。一般交付後等待使用者執行；只有已要求監看／等待中的工作才依約追蹤輸出。
