# 逐段 PCB 佈線與舊線處理

## 先界定這一段要完成什麼

使用者要求逐 bank、群組或差分對完成時，先做一個可驗收範圍。保留固定 connector pinout、群組對應、P/N 政策及既有蛇線等條件。明列指定 source ref/pin、destination ref/pin、net、位置、層與版本。

同名 net、端點配對通過或零匯出 warning，不等於銅線已接通。少量線先通過實際驗證，再依同一契約擴展；不把「分 bank preflight」命名或交付成 autorouter。

## 建立銅線前需要的證據

| 資料 | 缺少時能做什麼 |
|---|---|
| 當前指定端點與板檔身份 | 整理候選 mapping；先取得新鮮端點盤點 |
| 相關層 pin／via pad、阻焊與鑽孔等所需形狀、既有路徑 | 列資料需求與概念路徑，不交付未檢查幾何的畫線 apply |
| 完整局部障礙：其他 net、無 net 銅、shape、keepout、板邊 | 標出匯出缺口；net-owned dump 不能代表可用走線通道 |
| 疊層、參考平面、目標阻抗、適用層的線寬／差分間距 | 保留使用者提供值與來源，不能將一層幾何套到其他層 |
| 實際生效的 clearance、region／class-to-class 覆寫 | 預覽未知區域；default CSet 讀值不等於最終規則 |
| 長度／skew、速率、通道與機構要求 | 指出可做的局部工作與尚不能通過的電氣／SI驗收 |

資料可由版本適用的唯讀 API、正式匯出、規則檢視及必要畫面互補。缺某 API 時縮小結論，不用猜測值補齊。solver 數字需保留輸入／設定來源；阻抗近似目標不能單獨證明損耗、回流、時序或整條通道通過。

## 路徑 preview

交付具體候選線段／弧線、層、線寬／間距、接入點及與局部障礙的檢查範圍。使用者偏好表層時優先規劃；需要換層／新增 via，先列出哪一對、位置、數量、原因、參考平面與待驗證影響。不要默默接受舊 via 作為已核准的新方案。

預覽同時列舊物件的 KEEP／REMOVE／RECONNECT 與新建物件。辨識內層舊線、通孔、分支及未接線尾，避免新增平行路徑後留下 stub。不能按 net 名或單一座標界線刪整個網路；核對具體物件與完整連接關係。刪除範圍依使用者授權，替代路徑與可恢復方式需可檢視。

## 保留蛇線／整組搬移

先定義保留物件、完整幾何與區外重接點，再確定整組平移量。比較 trace／arc 的端點、曲率、層、線寬、via、net、拓樸及完整線長／skew；預期可變屬性與不變屬性分開。

CAD 搬移可能重整或拆合走線、改變連接及 net 歸屬。path 數變化是調查線索，數量相同也不是幾何保留證明。以指定平移的幾何等價與連通關係判定，不只匹配物件 ID；無法證明時停止後續刪線／提交。

若搬移後原待刪物件失配，不把 missing 當成已刪除或直接跳過。保存每一步的中間讀回，在受控試驗中定位第一次變化；也檢查未搬動銅箔的 net。新的連通或 net 變化可能比 API 錯誤更重要，原因未明前不得將試驗整理成成功配方。

## 套用及驗收

依已核准範圍產生明確 apply；先以 live 設計比對 preview 版本、物件與前置條件。每次只修改足以驗證的範圍，記錄完整操作與讀回。操作中斷或逾時先盤點，避免重複畫線或刪除。

本段驗收分別回答：

1. 指定 ref/pin 間是否有實體銅線連通，P/N、net及額外分支是否正確。
2. 新線、舊線及 via 是否符合核准清單，非目標幾何與 net 是否保持不變。
3. 實際路徑的適用層、線寬、clearance、回流與相關 DRC 是否經核對。
4. 完整線長／skew、通道／SI及機構條件有哪些已驗證或仍 pending。
5. 活資料 apply、BRD 儲存／重開核對各是什麼狀態。

無法通過的項目明列證據缺口及下一步；不能因一對端點通過就擴大宣稱整個 bank 已完成。失敗回復流程見 [驗證與恢復](verification.md)。
